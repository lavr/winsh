# winsh v0.1 Implementation Plan

> Execute inline using executing-plans; tests precede implementation.

**Goal:** Publish a working standalone WinRM CLI in lavr/winsh.
**Architecture:** main -> cmd -> remote; secret input is a separate package.
**Tech stack:** Go, pinned go-winrm fork, established NTLM and x/text packages.
**Spec:** ../specs/2026-09-08-v0.1-design.md

## Global constraints

Apache-2.0; generic examples only; no password argv or disk persistence;
CGO_ENABLED=0; no interactive default; four target platforms.

## Tasks

- [x] Credentials and CLI contract: write failing table tests for missing,
  conflicting and stdin passwords; command separator, script file, domain and
  endpoint validation; fake Runner returns distinct stdout/stderr and status.
  Implement `cmd.Run(ctx, args, Deps) int` and `secret.Read(env, stdinMode,
  stdin, lookup) (string, error)`. Run `go test ./internal/secret ./internal/cmd`.
- [x] WinRM runner: test UTF-16 script encoding (including supplementary Unicode),
  explicit output codepages, endpoint validation and HTTP transport against
  httptest. Implement `remote.Run(ctx, Request, stdout, stderr) (int,error)`
  with bounded HTTP contexts and verified TLS. Exercise WSMan create/command/
  receive/delete flow and remote rc against a local fixture server.
- [x] HTTP NTLM sealing: test frame round trips, truncated/tampered input and
  bounds using a test security session. Use bodgit NTLM session Wrap/Unwrap;
  establish a new authenticated connection per exchange, forbid unencrypted
  downgrade, redirects and proxy routing. Run all tests with race detection.
- [x] Delivery: README, CLI/tunnel docs, optional Windows smoke test, Makefile,
  CI/release workflows and noninteractive release.sh. Run gofmt, go vet,
  unit/integration/race tests, govulncheck and four static cross-builds. Audit
  tracked files for private infrastructure data. Commit, create public repo,
  push main, verify GitHub CI, and update the kb plan with project link.

## Validation record (2026-09-08)

Go 1.26.6; unit, race, integration fixture and four CGO-disabled builds passed.
The initial live Windows test skipped without endpoint configuration.
A subsequent explicitly configured run passed on Windows Server 2016 and 2019.
Independent pyspnego 0.12.2 validated the full encrypted HTTP exchange.
Fuzzing covered approximately 490k Type2 and 80k multipart inputs without panic.
Govulncheck reported zero affected symbols/imported packages.
Publication target is public github.com/lavr/winsh; GitHub Actions verifies main.
